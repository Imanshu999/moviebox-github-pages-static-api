Website integration · JavaScript

Use this in a browser or web app. Change the base URL if you host your own compatible catalog.

const API = "https://imanshu999.github.io/moviebox-github-pages-static-api/v1/";
const response = await fetch(API + "catalog.json");
if (!response.ok) throw new Error("Catalog request failed");
const catalog = await response.json();
const titles = catalog.results;

Current contract & limitations

  • Static JSON catalog is refreshed by GitHub Actions; no always-on server is required.
  • Search and filters run on the client using the downloaded catalog.
  • Static catalog currently guarantees metadata fields only.
  • Season, episode, audio, subtitle and playable stream details are only available if the provider returns them and the API exports them.
  • GitHub Pages cannot run the Rust Axum process. The existing Axum binary remains available for optional self-hosting, but this setup does not require it.
